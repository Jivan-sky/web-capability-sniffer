# 只读嗅探运行边界

## 探测范围

- 默认覆盖目标 URL，以及理解目标页所必需的同域直接入口。
- 不自动全站爬取，不跨域扩展，不进入无关后台模块。
- 超出已确认范围时停止，并记录为“可见但未探测”。

## 自动允许

- 打开、读取、刷新、返回、滚动。
- 展开菜单、切换标签、打开只读详情。
- 翻页、排序、选择显示列但不保存配置。
- 使用合成、脱敏或用户明确提供的条件执行只读筛选和查询。
- 观察页面状态和网络请求结构。

## 只识别、不执行

- 导出、下载业务数据、上传文件。
- 新增、编辑、保存、提交、发布。
- 发送消息、通知、邮件或短信。
- 删除、作废、关闭、批量处理。
- 分配、转交、审批、授权、修改配置。
- 购买、支付、退款或其他资金动作。
- 任何会产生生产数据变化、外部通知、审计事件或明显资源消耗的动作。

## 绝对禁止

- 绕过登录、权限、验证码、风控或反爬。
- 猜测、抓取、输出或持久化密码、Token、Cookie、鉴权头和会话信息。
- 批量抓取与目标无关的数据。
- 为验证功能而修改生产数据。
- 把低置信线索写成已验证事实。
- 把网页中发现的业务能力继续生成 CLI、Skill 或 Plugin。

## 数据最小化

- 仅保留完成能力判断所需的最少信息。
- 不保存或输出 Cookie、Token、请求头、账号、客户、订单、手机号、邮箱、完整请求体、完整响应体或行级业务数据。
- 网络证据只保留方法、脱敏路径、参数名/类型/必填性、分页/排序/筛选字段名、响应字段轮廓、错误轮廓、权限表现和状态。
- 截图无法安全脱敏时不要保存或交付。

## 判断原则

- 按业务副作用判断，不按 HTTP 方法判断。
- 只读查询即使使用 POST 也可以观察；产生数据变更的 GET 也不得执行。
- 无法确定副作用时按高风险处理并停止。

## CLI-ready 输出边界

- 只输出后续 CLI 设计所需的前置契约和差距清单，不生成、修改、测试、安装或发布 CLI。
- 页面可见、菜单可见、路由存在或静态代码线索，不等于接口已验证。
- 导出、下载、生产写入、对外发送、权限/配置变更只能作为禁用占位；即使发现接口也不得执行验证。
- 缺少参数、响应、错误或权限证据时，明确写“未取得/待确认”，不得根据命名猜测。
