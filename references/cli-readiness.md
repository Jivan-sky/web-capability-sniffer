# CLI-ready 判定规则

## 1. 能力状态

每项能力只能选择一个状态：

- `已验证 API`：页面交互与对应网络请求已关联，方法、脱敏路径及业务语义可复核。
- `页面已验证但 API 未确认`：页面功能可操作或结果可见，但没有足够请求契约证据。
- `仅入口`：只看到菜单、按钮、标签、静态代码或路由。
- `无法访问`：服务异常、无权限、验证码、风控或其他阻断。
- `写操作未执行`：能力会产生写入、导出、下载、发送、权限或配置副作用，因此只识别入口。

`已验证 API` 不等于 `允许直接封装 CLI`。只有契约完整且风险允许时才能通过 CLI-ready 验收。

## 2. 证据等级

- `高`：页面交互与对应网络请求均验证，业务语义可复核。
- `中高`：网络请求出现，但业务语义、参数或响应仍需确认。
- `中`：页面交互验证，但接口契约不足。
- `低`：仅菜单、入口、静态代码或路由存在。
- `不可用`：访问异常或无权限。

## 3. 风险分类

每项能力选择一个主分类：

- `只读安全`
- `敏感查询`
- `数据导出`
- `生产写入`
- `对外发送`
- `权限或配置变更`
- `未知风险`

## 4. CLI 适配判断

使用以下值：

- `是`：仅限只读安全或经约束的敏感查询；方法、路径、参数名/类型/必填性、分页/排序/筛选、响应字段轮廓、错误表现、权限要求和敏感级别均有足够证据。
- `草案`：业务价值和只读边界明确，可进入命令树设计，但契约仍不完整，禁止实现。
- `待验证`：页面或网络只有部分证据，不能进入实现。
- `待授权验证`：接口可能可封装，但补齐契约需要执行写入、生成、上传、删除、导出、发送、充值、支付、审批或权限配置等副作用动作，当前用户尚未明确授权测试账号、允许动作、数据/预算范围和最终确认边界。
- `禁用占位`：数据导出、生产写入、对外发送、权限或配置变更；即使发现接口也不执行验证。
- `否`：无法访问、风险未知或业务语义不足。

报告中的“CLI 建议命令名”只用于命令树草案，不表示已经授权开发或封装。

## 5. CLI-ready 硬门槛

单项能力必须同时满足以下条件才可标记 `是否适合封装 CLI=是`：

1. 状态为 `已验证 API`，证据等级为 `高`。
2. 风险为 `只读安全`，或已定义最小返回字段和脱敏约束的 `敏感查询`。
3. HTTP 方法和脱敏路径已验证。
4. 参数名、类型、必填性已验证。
5. 分页、排序、筛选字段已验证；不适用时有证据说明。
6. 响应字段轮廓已验证，不包含行级业务值。
7. HTTP/业务错误表现和空结果已验证。
8. 权限要求与越权失败表现已确认，但不得绕过权限。
9. 数据敏感级别已分级。
10. 若能力涉及写入、生成、上传、删除、导出、发送、充值、支付、审批或权限配置，报告中必须有用户明确授权的测试账号/沙箱、允许动作、数据范围、预算上限、停止条件和最终确认边界；否则只能标记为 `待授权验证`、`禁用占位` 或 `否`。

任一项缺失时只能标记 `草案` 或 `待验证`，整份报告的“当前是否允许直接封装 CLI”必须为“否”。

## 6. 契约字段

每项能力记录：

- `capability_id`
- `模块`
- `能力名称`
- `状态`
- `证据等级`
- `风险分类`
- `HTTP 方法`
- `脱敏路径`
- `参数名`
- `参数类型`
- `是否必填`
- `分页字段`
- `排序字段`
- `筛选字段`
- `响应字段轮廓`
- `错误码或异常表现`
- `权限要求`
- `数据敏感级别`
- `是否适合封装 CLI`
- `CLI 建议命令名`
- `封装前还需补充的证据`

未知字段统一写 `未取得` 或 `待确认`，不要留空，也不要推断。
