# 探查工作流

## Preflight

先做运行前权限边界确认，再开始任何浏览器或网络探查。若本轮用户没有明确目标 URL、账号性质、目标交付、允许操作类别、禁止操作类别和最终确认边界，先询问并等待回复。

运行前问题不得预设目标站具备哪些功能。只读 CLI 可以只执行只读接口；涉及创建/写入、修改/保存、上传、下载/导出、删除、对外发送/公开、资金交易、凭据/账号/权限配置或明显资源消耗的 CLI 必须取得对应操作类别授权，否则只能输出待授权验证项。

目标范围默认按用户给定 URL 的同 origin 前缀探查。例如 `https://app.example.com/home` 默认覆盖 `https://app.example.com/` 前缀下页面、路由和接口；跨 origin、跨租户和第三方入口另行授权。

## Scope

记录目标、时间、登录态、角色线索、系统边界、默认深度和安全策略。没有明确授权时只探查目标页和同域直接入口。

## Map

1. 打开默认落地页并记录标题、URL 轮廓、可见区域和加载异常。
2. 识别一级导航、顶部入口、全局按钮、搜索、筛选、列表、详情、表单、弹窗、iframe 和画布。
3. 每个入口先创建 `Feature`，即使只看到入口也保留状态。
4. 将一级导航、顶部入口、全局能力和二级菜单分开统计，不要混加。

## Explore

允许自动执行：

- 打开、刷新、返回、滚动。
- 展开菜单、切换标签、打开只读详情。
- 翻页、排序、选择显示列但不保存配置。
- 使用合成、脱敏或用户明确提供的条件执行只读筛选和查询。

只识别不执行：

- 导出、下载、上传。
- 新增、编辑、保存、提交、发布。
- 发送消息、通知、邮件或短信。
- 删除、作废、关闭、批量处理。
- 分配、转交、审批、授权、配置修改。
- 购买、支付、退款或其他资金动作。

## Capture

- 每个业务目标形成一个 `Flow`，每个页面动作形成一个 `Step`。
- 捕获动作前后的语义快照、可见结果、错误提示和新增网络请求。
- 截图仅用于布局、画布、虚拟列表等语义快照不足的场景；无法脱敏时不要保存。
- 网络记录只保留契约轮廓，不保留值。

## Normalize

- 合并同义功能，保留所有入口证据。
- 将功能归入模块、角色、页面、业务流程和发布用途。
- 将重复请求合并为请求契约索引。
- 对无法复核的条目标记为 `仅推断` 或 `待确认`。

## Flow 验证

第一阶段只对少量核心 Flow 做按需验证：

- 优先选择只读、安全、业务价值高、步骤短的 Flow。
- 验证最小可重放线索：入口、动作、等待条件、断言轮廓、预期结果。
- 不建设完整自动化测试体系，不做定时或 CI 执行。
- 若需要 Playwright，仅生成或验证关键路径的最小脚本线索。

## Publish

同一份 Flow 可以生成：

- 功能地图：模块、功能、角色、状态、证据等级。
- 操作手册：按角色和流程生成步骤说明。
- 培训材料：按业务场景组织关键流程、注意事项和常见错误。
- API/CLI 候选：仅从已验证网络证据中提炼。
- 自动化候选：只读、稳定、可重放的关键 Flow。
