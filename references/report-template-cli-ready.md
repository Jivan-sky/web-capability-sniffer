# CLI-ready 复嗅探报告模板

用于**同一目标系统的复嗅探**（第二次及以后）或 **CLI-ready 验收**：重点输出能力分层、CLI-ready 契约、请求契约索引、差距清单和验收结论，不重复完整探查报告的 Feature / Flow / Step 三层明细。

首次完整探查仍用 [report-template.md](report-template.md)。

结构校验：

```bash
python3 <skill-dir>/scripts/validate_report.py <report.md>
```

`validate_report.py` 自动识别本模板与 `report-template.md` 两套格式，并打印识别结果。
