# CLI-ready 复嗅探报告模板

用于**同一目标系统的复嗅探**（第二次及以后）或 **CLI-ready 验收**：重点输出能力分层、CLI-ready 契约、请求契约索引、差距清单和验收结论，不重复完整探查报告的 Feature / Flow / Step 三层明细。

首次完整探查仍用 [report-template.md](report-template.md)。

结构校验：

```bash
python3 <skill-dir>/scripts/validate_report.py <report.md>
```

`validate_report.py` 自动识别本模板与 `report-template.md` 两套格式，并打印识别结果。

### 2.2 探测方式

- 登录态来源、浏览器任务空间、自动允许动作、响应字段提取方式、脱敏策略。
- 运行前权限边界确认：已完成；账号性质/只读角色证明：`<只读账号/客户正式只读角色>`。
- 证据来源类型：`runtime_observed` / `user_confirmed` / `repository_artifact` / `document_clue` / `hypothesis` 的使用范围。
- 请求来源：页面自身触发；未复制、未重放、未导出 HAR、未保存完整请求/响应。
- 运行时写保护：`已启用`（guard 位置/版本、`allowReadPostPaths` 与 `allowSessionPostPaths` 是否为空/每个精确路径及 owner 确认、阻断次数）或 `未启用`（原因 + 补偿控制 + 残余风险接受人）。
- 数据库直连：`否`；如另立只读数据核对，写只读副本/只读凭证/只读事务/超时证据。

## 4. 能力与命令树分层

| capability_id | 层级 | 能力 | 状态 | 证据等级 | 风险分类 | CLI适配 | CLI建议命令名 |
|---|---|---|---|---|---|---|---|

- `状态`：`已验证 API`、`页面已验证但 API 未确认`、`仅入口`、`无法访问`、`写操作未执行`。
- `CLI适配`：`是`、`草案`、`待验证`、`待受控交付`、`禁用占位`、`否`。`是` 只能用于只读安全或敏感查询；写入、导出、发送、权限/配置变更只能 `待受控交付` 或 `禁用占位`。
- 本表每个 `capability_id` 必须同时出现在第 5 节，反之亦然。

## 5. CLI-ready 契约表

字段与 [cli-readiness.md](cli-readiness.md) 第 6 节一致：

| capability_id | 模块 | 能力名称 | 状态 | 证据等级 | 风险分类 | HTTP 方法 | 脱敏路径 | 参数名 | 参数类型 | 是否必填 | 分页字段 | 排序字段 | 筛选字段 | 响应字段轮廓 | 错误码或异常表现 | 权限要求 | 数据敏感级别 | 是否适合封装 CLI | CLI 建议命令名 | 封装前还需补充的证据 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

`是否适合封装 CLI`：`是`、`草案`、`待验证`、`待受控交付`、`禁用占位`、`否`。取 `是` 时必须同时满足 `cli-readiness.md` 第 5 节全部硬门槛；校验器会核对状态/证据等级、方法、脱敏路径、参数名/类型/必填性、分页/排序/筛选、响应、错误、权限、敏感级别、命令名和剩余证据，人工仍需复核证据真实性与业务语义。写操作能力永远不能取 `是`。
- 写风险能力的 `状态` 只能是 `写操作未执行`；`未知风险` 能力不得标 `已验证 API`，CLI 适配只能是 `禁用占位`、`待受控交付` 或 `否`。不得因为客户授权或发现了接口而放宽。
