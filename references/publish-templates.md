# 发布物模板

## 功能地图

字段：

- `feature_id`
- `模块`
- `页面/入口`
- `功能名称`
- `角色线索`
- `状态`
- `风险分类`
- `证据等级`
- `关联 flow_id`
- `关联 evidence_id`
- `人工审核建议`

## Flow 清单

字段：

- `flow_id`
- `流程名称`
- `所属 feature_id`
- `角色/前置条件`
- `触发入口`
- `Step 列表`
- `可重放状态`
- `验证状态`
- `输出用途`

## Step 证据表

字段：

- `step_id`
- `flow_id`
- `动作类型`
- `目标/选择器线索`
- `输入数据策略`
- `页面结果`
- `网络证据`
- `副作用判断`
- `可重放线索`

## Evidence 索引

字段：

- `evidence_id`
- `来源类型`
- `采集方式`
- `触发 step_id`
- `脱敏 URL/路径`
- `请求轮廓`
- `页面轮廓`
- `置信度`
- `限制/盲区`

## 操作手册草稿

按角色和 Flow 输出：

1. 适用角色和使用场景。
2. 前置条件。
3. 操作步骤。
4. 成功结果。
5. 常见异常。
6. 注意事项。

不要包含真实客户、订单、账号、手机号、邮箱、Token、Cookie 或行级业务数据。

## 培训材料草稿

按业务场景输出：

- 场景目标。
- 相关模块。
- 推荐流程。
- 关键判断点。
- 常见误区。
- 需人工确认事项。

## API/CLI/Agent Skill 候选

仅从已验证网络证据生成候选：

- `候选 ID`
- `来源 feature_id/flow_id`
- `候选类型`：API、CLI、Agent Skill、自动化脚本。
- `业务价值`
- `只读边界`
- `所需证据`
- `当前状态`：可设计、草案、待验证、禁用、不建议。
- `缺口`

CLI-ready 的详细字段继续使用 `cli-readiness.md`。
