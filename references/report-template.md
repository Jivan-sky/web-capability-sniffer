# CLI-ready 嗅探报告模板

## 1. 明确判断

- 当前是否允许直接封装 CLI：`是/否`
- 判断依据：`<一句话结论>`
- 可进入 CLI 命令树草案：`<能力 ID 列表或无>`
- 禁用占位：`<能力 ID 列表或无>`
- 待验证/无法访问：`<能力 ID 列表或无>`
- 关键缺失材料：`<参数、响应、错误、权限等>`

## 2. 范围、口径与安全结果

分别统计：

- 一级导航模块
- 顶部入口
- 全局能力
- 二级菜单能力

记录目标 URL、时间、深度、合法登录状态、异常、数据最小化方式，以及生产副作用、敏感信息泄露、权限绕过是否均为 0。

## 3. 证据等级与风险规则

逐项列出 `高/中高/中/低/不可用` 定义，以及 `只读安全/敏感查询/数据导出/生产写入/对外发送/权限或配置变更/未知风险` 分类。

## 4. 能力与命令树分层

按一级导航、顶部入口、全局能力、二级菜单能力列出能力 ID、状态、证据等级、风险、CLI 适配判断和建议命令名。

## 5. CLI-ready 契约表

每项能力必须包含 [cli-readiness.md](cli-readiness.md) 定义的全部 21 个字段。表格过宽时允许按能力使用字段表，但不得省略字段。未知信息统一写“未取得/待确认”。

## 6. 当前报告差距清单

按缺失字段、受影响能力、阻断级别和最小补证方式列出差距。

## 7. 请求契约索引

仅列方法、`origin + pathname`、触发动作、响应字段轮廓、错误轮廓和证据等级。不得包含参数值、请求头、Cookie、Token、完整请求/响应或行级业务数据。

## 8. 风险与未执行动作

逐项列出识别但未执行的数据导出、生产写入、对外发送、权限/配置变更及未知风险动作。

## 9. 异常与盲区

列出无法访问、未执行、仅推断、动态区域、权限不足、失败路径和停止原因。

## 10. 验收结论

必须分别回答：

- 嗅探报告验收是否通过
- CLI-ready 验收是否通过
- 不能通过的具体原因
- 下一步最小补探清单
- 需要只读验证的接口
- 即使发现也不能执行的接口/动作
- 当前是否允许直接封装 CLI

## 11. 结束边界

只给补探和交接建议；不要生成、修改、测试、安装或发布从目标网页发现的 CLI、Skill 或 Plugin。
